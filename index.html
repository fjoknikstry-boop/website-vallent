// FAQ

Questions,
answered.

Is VALLENT EXS actually free?
Yes — moderation, anti-nuke, leveling, tickets, and giveaways all run on the free tier with no paywall. Premium only unlocks cosmetic and convenience extras like custom card gradients and no-prefix commands.
What permissions does it need?
Standard moderation permissions (kick, ban, manage roles/channels) so it can actually act on warns, bans, and anti-nuke responses. You can review and trim the permission set during the Discord invite step.
How do I configure everything?
Either from Discord directly with prefix or slash commands, or from the web dashboard — log in with Discord, pick a server, and toggle systems, channels, and role rewards from a browser.
How do I get Premium?
Check out the pricing page and pick a plan — checkout runs through the dashboard once you're logged in with Discord.
Is my server's data safe?
Only what's needed to run each feature is stored (settings, XP, ticket transcripts). See the privacy policy for the full breakdown of what's collected and why.
Where do I get help if something breaks?
Join the support server — that's where updates, bug reports, and direct help all happen.
