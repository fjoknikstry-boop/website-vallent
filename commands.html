Embed Builder

A per-user draft you build piece by piece, then send whenever it's ready. Admin/owner only.

embed title / description / append / separatorWrite the embed's content.Admin
embed thumbnail / banner / colorStyle it — URL or attach an image directly.Admin
embed channel #channelChoose where it'll be sent.Admin
embed edit <link/ID>Load an existing message back into the draft to edit it.Admin
embed link add / remove / listAttach link buttons below the embed.Admin
embed preview / send / resetPreview the draft, publish it, or start over.Admin
🔘

Message Component Builder

Same builder as Embed, plus interactive buttons. Buttons can be a link (opens a URL) or a response (shows the clicker an ephemeral message). Reuse the same ID later to edit that message instead of posting a new one. Admin/owner only.

component <id> #channelOpen the builder for a given message ID and target channel.Admin
💤

AFK System

Sending any message automatically clears your AFK status. Anyone who @mentions you while you're AFK gets notified with your reason. Only a limited number of members can be AFK at once per server — voting for the bot temporarily unlocks a slot once it's full.

afk [reason]Set yourself as AFK, optionally with a reason. Alias: away.
